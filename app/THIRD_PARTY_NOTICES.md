# Third-party notices

## Ravenswatch Mod Manager

The approach of decoding icons and text from the player's own game install
at runtime, rather than shipping decoded files, follows Ravenswatch Mod
Manager by Ovilli (https://github.com/Ovilli/RavenswatchModManager), MIT
License. No code from that project is included; `assets/` is an
independent implementation for this app's renderer.

The unmodified Germania One font by John Vargas Beltran and Alegreya Sans
fonts by Huerta Tipografica are bundled under the SIL Open Font License 1.1.
